旧页面的四个问题

  • 「当前外观」巨卡大半空白——一段进度条 + 两个按钮撑满 400px 高。
  • 固定主题横向滚动，7 个里永远只能看到 3 个半（截图里石墨被裁一半），不可发现的选项等于不存在。
  • 四张色调面板（背景/主操作/选中/链接）结构完全相同却各占一屏高，重复啰嗦。
  • 改一个颜色看不到全貌——预览卡在最顶上，色板在最下面，来回滚。

新结构与 Flutter 落点

  • 英雄预览：色板簇 + 名称摘要 + 紧凑 mini mock（海报排 + 主按钮 + 选中标签 + 进度 + 更多），高度 ~150。改任何颜色它都变——ThemeSettingsPreviewCard 重写为紧凑版。
  • 固定主题：横向滚动改 网格（桌面 4 列 / 手机 2 列，GridView），7 个预设全部可见、选中态环标。
  • 色调面板：四张巨卡压成 一张卡四行，每行 = 色块 + 名称 + 内嵌色板圈 + 调色盘入口；点色圈即生效，自定义徽章跟随。
  • 动态取色、自定义主题（当前配方入口 + 已保存网格）压缩为同语言卡片；文案全部沿用现有 theme* l10n。
  • 颜色一律 context.appColors 通用取色（卡片描边/文字/选中环），预览内容用 provider.previewColorsForPreset 等现有数据。
