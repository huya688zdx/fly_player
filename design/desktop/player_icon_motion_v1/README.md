# 播放器图标动效预览

本目录保留制作阶段的视觉方案。透明图标及进入、退出动作现已接入桌面播放器的 `desktop_player_motion_icon.dart` 和 `desktop_player_controls.dart`，并扩展到 AB 循环入口；运行时直接绘制笔画，不播放本目录的循环预览素材。

先使用内置 imagegen 生成七个图标的造型参考 `source-atlas.png`，再按参考拆开屏幕、线条、文字、音符和四角等部件。`render_preview.py` 输出 PNG 关键帧，再逐帧合成为 7.2 秒循环动画。动画中的运动来自图形部件变化，不依赖底色切换，也没有对不同文字做叠帧淡化。

- `preview.webp`：30 fps 动画。
- `preview.gif`：15 fps 兼容预览。
- `icons-transparent.webp`：30 fps 真透明动画，只包含七个图标，可叠加到视频画面。
- `keyframes.png`：透明背景的四个进入关键帧，按七个图标排列。
- `states.png`：默认状态与选中状态，包含实际工具栏尺寸。
- `icon-*-off.png` / `icon-*-on.png`：单个图标的静态状态图。

| 图标 | 选中 / 展开 | 取消 / 收起 |
| --- | --- | --- |
| 弹幕 | 三行弹幕从右向左穿行 | 反向收回 |
| 倍速 | 数字向上滚动归位 | 数字向下滚动归位 |
| 选集 | 三行条目错峰伸展 | 反向收拢 |
| 画质 | 边框聚焦、HD 轻微放大归位 | 反向聚焦归位 |
| 字幕 | 字幕笔画逐行写入 | 笔画逐行收回再归位 |
| 音轨 | 两个音符交错跳动，连线随动 | 反向跳动归位 |
| 全屏 | 四角向外展开并保持 | 四角向内收回 |

图标没有背景底板、按钮外框和额外状态标记。选中时仅图形笔画由白色变为浅蓝色，图形动作保留。菜单图标的选中表示菜单展开，不表示字幕或音轨被关闭。预览中的深色画布仅用于展示，单个 PNG 和透明 WebP 不包含该画布。

在 Windows 安装 Pillow 后运行 `python design/desktop/player_icon_motion_v1/render_preview.py` 可重新生成。绘制使用系统微软雅黑字体，无新增项目依赖。

生成图提示词要点：七列两行的桌面视频播放器图标状态图；统一圆角、白色线框；依次为屏幕弹幕线条、1.0×、选集列表、HD、字幕、音符、全屏四角；上下两行保持同一图形造型。原始生成图仅保留为造型参考；最终动画按用户要求去掉背景颜色，采用透明图标和部件运动。
