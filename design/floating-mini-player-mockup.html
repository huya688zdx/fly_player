安卓 · 交互演示清单

  1. 进小窗：播放页一键收缩为悬浮小窗，应用退到「桌面」，播放不中断（方案 3.4）；交接空洞由定格图覆盖（P3 预算 <200ms，方案 5.2）。真机悬浮窗需 API 26+ 与悬浮窗权限，低版本 / 未授权自动回退系统画中画（方案 3.2）。
  2. 拖动：按住小窗自由拖动，可拖出屏幕边（模拟 FLAG_LAYOUT_NO_LIMITS）；松手吸附左 / 右边缘（方案 3.2）。
  3. 边缘缩放：拖小窗任意边缘 / 角自由等比缩放（对齐系统画中画手感，无档位），宽 160px 至屏宽 72%；松手吸附并按新尺寸重设 android-surface-size（方案 3.3）。
  4. 单击小窗呼出控制层：中央播停大按钮、±15s、锁定、选集、弹幕开关、关闭、展开回全屏（方案 0 / 3.5）。
  5. 接下来播放：点「下一集」图标模拟进程内就地换片——标题与进度重置（方案 3.5 dispatchInPlaceLoad）；小窗内也可点选集换集——选集面板可滚动（26 集演示长剧集不截断），打开自动定位当前集。
  6. 弹幕：CSS 动画横向飘过；关闭后完全停止渲染（方案 5.3 零弹幕成本）；暂停时弹幕同步停住。
  7. FPS 实测表：右下角常驻，拖动小窗时观察流畅度（方案 5.1 P1/P4 的前端可感知版本）。

视频画面为 CSS 渐变动画占位；标签页切换不丢状态；全部交互纯前端模拟。

PC · 交互演示清单

  1. 进小窗：主窗口缩为顶部居中的置顶迷你窗（方案 4 候选 A：保存窗口态 → 缩尺寸 → setAlwaysOnTop）。
  2. 拖动：迷你窗整体任意拖动（对应 windowManager.startDragging 先例），主窗口 / 备忘录也可拖标题栏。
  3. 置顶遮挡：点「备忘录」标题栏置前，或将迷你窗拖到它 / 任务栏上面——迷你窗永远在最上层。
  4. 迷你控制条：上一集 / −15s / 播停 / +15s / 下一集 / 还原；点视频缩略区也可播停；标题栏 ✕ 关闭（关闭即暂停，主窗口还原）。
