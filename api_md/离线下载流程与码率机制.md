# 飞牛影视：离线下载流程与不同码率机制（逆向 + 实测）

> 对象：影视 App 的**离线下载**功能（不是"下载中心"BT/PT，那是 dlcenter+aria2/qBittorrent，另一套系统）。
> 方法：trim-media 后端二进制符号逆向 + 在你的 NAS 上**真实创建/轮询/删除下载任务**实测（2026-09-06）。
> 可复用脚本：`probe_dl_create.py`、`probe_dl_put.py`、`probe_dl_progress.py`。

## 0. 一图看懂

```
App                          trim-media 后端                       mediasrv 转码引擎
 │ ① GET /download/resolution/{guid}  │
 │ ◄─ ["4k","1080p","720p","480p","Others"]（按源分辨率动态生成）│
 │ ② PUT /download/task {media_guid, resolution}│
 │ ───────────────────────────►│ "Others"→ 原文件直取/网盘直链        │
 │  ◄─ {data: 任务guid} ───────│ 1080p/720p/480p → 提交转码任务 ────►│ ffmpeg 转码出目标分辨率文件
 │ ③ GET /download/taskProgress?guid=任务guid                        │
 │ ◄─ {status, percents} ─────│（复用已完成转码；到期自动清理）       │
 │ ④ 经 nginx /multiple-download → multiple-downloads 服务按 Range 分块并行拉取产物
 │ ⑤ DELETE /download/task/{任务guid}（删除任务+产物；取消=CancelTranscodingTask）
```

## 1. 通用请求规格

与[转码字幕文档 §6.0](E:\NAS\转码字幕获取机制.md) 完全一致：`Authorization: <媒体token>` + `authx` 签名 + `X-Trim-Client: web` + `X-Trim-Client-Version: 616`。token 获取走 FN Connect 链或 `loginByPassword`（见 FN Connect 文档）。

## 2. 接口清单（全部实测）

### 2.1 `GET /v/api/v1/download/resolution/{guid}` — 查可选下载档位

- `{guid}` = 媒体文件 guid（或条目 guid，两者都接受）
- **档位按源视频分辨率动态生成**（实测对比）：
  - 4K 片源（电锯人 3840x1604）→ `["4k","1080p","720p","480p","Others"]`
  - 1080p 片源（16MB 样本）→ `["1080p","720p","480p","Others"]`（没有 4k）
  - `Others` = 原画/原始文件，始终存在
- 对应代码：`resolutiontype.MoreAndEqualsThan`（源分辨率 >= 档位才提供）
- 档位与播放画质徽章同一套（`8k` 复用 4k 档）

### 2.2 `PUT /v/api/v1/download/task` — 创建（或更新）下载任务

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `media_guid` | string | ✅ | 媒体文件 guid |
| `resolution` | string | ✅ | 档位：`"4k"/"1080p"/"720p"/"480p"/"Others"` |

响应（实测）：`{"msg":"","code":0,"data":"0f006c4458c54ecda51bcb09f905c73e"}` —— **data 就是任务 guid**。
注意：body 用 `guid`/`item_guid` 都不行，必须是 `media_guid`；路径 `PUT /download/task`（无 guid 段）。

### 2.3 `GET /v/api/v1/download/taskProgress?guid={任务guid}` — 查进度

| 参数 | 位置 | 说明 |
|---|---|---|
| `guid` | query | **创建任务时返回的任务 guid**（传 media_guid 会 -6 Not Found；不传 -1 Invalid Params） |

响应（实测）：
```json
{"msg":"","code":0,"data":{"status":0,"percents":0}}
```
- `status`: 0=初始/等待（枚举含 pending/processing/completed/failed 等，源码 `DownloadTaskStatus`）
- `percents`: 转码/下载进度百分比
- **实测踩到的错误**：`{"msg":"[mediasrv err]: forbidden cpu transcoding","code":68157464}`
  —— 低码率档位需要转码；该 NAS 开了 GPU 转码但**禁用了 CPU 转码**，GPU 不可用/不支持目标档位时下载转码直接失败。这是"下载失败"的高频原因。

### 2.4 `DELETE /v/api/v1/download/task/{任务guid}` — 删除/取消任务

实测：`{"msg":"","code":0,"data":true}`。后端同时 `CancelTranscodingTask` 停掉转码、清理产物；
另有过期自动清理（`GetExpireDownloadTaskList` → `delete download task %s expire`）。

## 3. 不同码率的后端处理路径（源码符号实证）

| 选择 | 后端行为 |
|---|---|
| `Others`（原画） | 不转码。本地文件走原始文件直取（`shouldUseOriginalMediaRange`）；**网盘/远程挂载条目走直链**（`get direct link for download task %s, url: %s`，配合云存储的 `direct_link_qualities` 续期机制） |
| `4k/1080p/720p/480p` | 提交 **mediasrv 本地转码任务**（`recreateLocalTranscodingTask`）：ffmpeg 转出目标分辨率文件（日志 `created download task, guid %s, media guid %s, media file %s, output file %s, resolution %s`）；**已完成的同参数转码直接复用**（`shouldReuseCompletedLocalTranscodeTask`）；GPU 优先，CPU 转码可被策略禁止（实测见上） |
| 字幕 | 随任务一起处理（`bo.SubtitleTranscodingTask`、`mediasrv.SubtitleOutputFile`，任务响应含 `subtitle_files`）——外挂/内嵌文本字幕会转成 vtt 伴随产物 |

## 4. 文件传输层（multiple-downloads 服务）

- 任务产物不通过 `/v/` 媒体接口下发，而是独立服务：nginx `location /multiple-download` → `unix:/var/run/multiple-downloads.sock`
- 客户端（App）按 **Range 分块 + 多连接并行**拉取（服务端日志格式 `=== range path %s start %d end %d fileSize %d`，分块大小字段 `part_size`）
- 产物定位用 `hash_path`（资源表 `uk_resource_download_target`：source_url + owner_type + owner_guid 唯一；`idx_resource_download_hash_path` 索引）
- 任务数据模型 `ResourceDownload`：`status` 默认 `pending`，`download_target/owner/next_retry/count` 等字段，调度器 `download/scheduler`

## 5. 完整调用序列（第三方复刻）

```http
GET  /v/api/v1/download/resolution/{media_guid}        → 选档位
PUT  /v/api/v1/download/task  {"media_guid":"...","resolution":"480p"}
     → data = task_guid
GET  /v/api/v1/download/taskProgress?guid={task_guid}  → 轮询 status/percents
     （status 完成 → 从 multiple-download 通道按 Range 分块拉文件）
DELETE /v/api/v1/download/task/{task_guid}              → 取消/删除
```

## 6. 与"下载中心"的区别（别混淆）

| | 影视离线下载（本文） | 下载中心（dlcenter） |
|---|---|---|
| 用途 | 把媒体库影片离线到 App | BT/PT/HTTP/磁力 下载到 NAS |
| 服务 | trim-media + multiple-downloads | dlcenter（每用户 aria2/qBittorrent 实例，`trim-aria2c`、`trim-qbittorrent-nox`） |
| 码率 | 可选转码档位 | 原始种子/文件，无转码 |
| API 前缀 | `/v/api/v1/download/*` | `/v1/dlcenter`（另属 dlcenter 服务） |
