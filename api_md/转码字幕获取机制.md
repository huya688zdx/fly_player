# 飞牛影视：转码时的字幕获取机制（逆向 + 实测验证）

> 承接 [飞牛影视API文档.md](E:\NAS\飞牛影视API文档.md)。全部结论来自前端代码逆向 + 在你的 NAS 上用真实媒体会话实测（2026-09-06）。
> 实测对象：《电锯人剧场版 蕾塞篇》（4K HEVC 杜比视界 + EAC3 + 34 条内嵌 SRT），发起真实转码会话并抓取 HLS 播放列表。

## 0. 一句话结论

**转码时字幕不单独"下载"，内嵌文本字幕被服务端实时转成 WebVTT 分段，作为 HLS 字幕轨道（`#EXT-X-MEDIA:TYPE=SUBTITLES`）随播放列表一起交付**；外挂字幕文件走独立下载接口 `/subtitle/dl/:guid`，由浏览器端渲染器（JASSUB/libass WASM 或原生 VTT）绘制；位图字幕（PGS/DVB）无法转文本，转码时直接**烧录进画面**。

## 1. 字幕轨的三种类型（stream/list 实测数据）

`GET /v/api/v1/stream/list/:item_guid` 返回 `subtitle_streams[]`，每条字段：

```json
{"media_guid":"...","guid":"...","title":"...","language":"chi","forced":0,
 "index":8,"is_default":0,"is_external":1,"codec_name":"webvtt",
 "format":"vtt","trim_id":"o5654949:0","Source":"opensubtitles",
 "extra_file":1,"is_bitmap":0,"file_size":0}
```

| 类型 | 判定字段 | 实测样本 | 交付方式 |
|---|---|---|---|
| 外挂字幕文件 | `is_external:1` / `extra_file:1` | ASS 外挂、OpenSubtitles 下载的 vtt（`Source:"opensubtitles"`） | `GET /subtitle/dl/:guid` 取原文件，前端渲染 |
| 内嵌文本字幕 | `is_external:0, is_bitmap:0`（如 mkv 里的 subrip） | 电锯人：34 条内嵌 `format:"srt"` | 转码时转 WebVTT → HLS 字幕轨 |
| 位图字幕 | `is_bitmap:1`（`codec_name:"hdmv_pgs_subtitle"`, `format:"sup"`） | 中二病剧场版：PGS 且 `is_default:1` | 转码时烧录进画面 |

前端判定函数（主 chunk `74c95604…js`）：
- `VZ(e)` = 非外挂 && 非 extraFile && 无 url && 非位图 → **此轨将被转成 vtt**（`format` 变 `vtt`，`formatDisplay` 保留原格式名供 UI 显示）
- `WZ(e)` = format ∈ {`sup`,`dvb`} → 位图字幕（播放报错提示有专门分支）
- 直连播放时列表过滤：只显示 `isExternal || extraFile` 的外挂字幕（内嵌轨走 remux/转码才有意义）

## 2. 转码会话的字幕交付（实测）

### 2.1 发起会话
```
POST /v/api/v1/play/play
{"item_guid":"<影片guid>","media_guid":"<文件guid>","video_guid":"<视频流guid>",
 "video_encoder":"h264","resolution":"1920x1080","bitrate":4000000,
 "startTimestamp":0,"audio_encoder":"aac","audio_guid":"<音频流guid>",
 "channels":2,"subtitle_guid":"<内嵌srt guid>"}
```
⚠️ `video_guid` 必须是 **video_streams[0].guid**（视频流 guid），不是文件 guid——否则报 1001 "System busy"（误导性错误码）。这些 guid 的官方推荐值来自 `POST /play/info {item_guid, media_guid}`。

响应关键字段：
```json
{"play_link":"/v/media/29ef304c9786ca0aa1eaa5882fb55eb7/preset.m3u8",
 "is_subtitle_external":0,
 "subtitle_link":"",            ← 内嵌字幕没有独立链接
 "subtitle_index":8,
 "hls_time":4}
```

### 2.2 播放列表（实测抓到的 preset.m3u8）
```
#EXTM3U
#EXT-X-VERSION:3
#EXT-X-INDEPENDENT-SEGMENTS
#EXT-X-MEDIA:TYPE=SUBTITLES,GROUP-ID="subs",NAME="SUBS",DEFAULT=YES,FORCED=YES,AUTOSELECT=YES,URI="subtitle.m3u8"
#EXT-X-STREAM-INF:BANDWIDTH=4000000,VIDEO-RANGE=SDR,CODECS="avc1.640029,mp4a.40.34",RESOLUTION=3840x1604,FRAME-RATE=23.976,SUBTITLES="subs"
main.m3u8
```
- `main.m3u8` = 视频转码分段（H.264 4 秒一段，`hls_time:4`）
- `subtitle.m3u8` = **WebVTT 字幕分段播放列表**（与会话同目录 `/v/media/<会话id>/subtitle.m3u8`）
- 前端 hls.js 配置 `enableWebVTT:true`，字幕轨自动出现，无需任何单独请求

### 2.3 播放中切换字幕
`POST /v/api/v1/media/p`（RPC 信封）：
```json
{"req":"media.resetSubtitle","reqid":"1234567890ABCDEF",
 "playLink":"/v/media/.../preset.m3u8","startTimestamp":<当前秒>,"subtitleIndex":<新轨index>}
```
服务端更新会话的 `subtitle.m3u8` 指向（视频流不受影响，实现无缝切换）；前端随后触发 `SubtitleChanged` 事件刷新轨信息。外挂字幕（有 `url` 的）则本地直接切换，无需请求服务器。

## 3. 外挂字幕的获取与渲染

| 环节 | 接口 / 机制 |
|---|---|
| 列表 | `stream/list` 的 `subtitle_streams[]`（含在线字幕，`Source:"opensubtitles"` 等） |
| 在线搜索 | `POST /subtitle/search` |
| 下载到 NAS | `POST /subtitle/download`（存库时已转 vtt：实测 OpenSubtitles 中文字幕 `codec_name:"webvtt", format:"vtt"`） |
| 预下载 | `POST /subtitle/predownload` |
| 取字幕内容 | `GET /v/api/v1/subtitle/dl/:guid`（specialApi，免 authx 签名）——实测直接返回 WEBVTT 正文 |
| 删除 | `DELETE /subtitle/del` |
| 上传本机字幕 | `POST /subtitle/upload/:media_guid`（免签名） |
| 标记/偏好 | `PUT /subtitle/mark` |

**前端渲染器分两条路**（`bf29a647…B0WFpgby.js`）：
- `format ∈ {vtt, srt}` → VTT/SRT 渲染器（原生 textTrack / 内置解析器，支持分段 VTT `enableVttSegmentation`）
- `format ∈ {ass, ssa}` → **JASSUB**（libass WASM，canvas 叠加渲染，保留特效字幕样式）
  - worker：`/v/assets/e1874b4c08f82ddc87f553e55d0f9be8-DAOUR0c6.js`
  - wasm：`/v/assets/f9a22872f07b0d7d76c83fae023acc8f-BG4vIwJE.wasm`
  - 字体可注入，支持 offset/安全区设置

## 4. 位图字幕（PGS/DVB）

- `is_bitmap:1`，无法转文本 → 转码会话中由 ffmpeg **烧录（burn-in）进视频画面**，字幕不单独存在
- 这也是"明明浏览器能播却触发转码"的常见原因：选了 PGS 默认轨（蓝光原盘常默认）
- 前端在播放报错场景对 `sup/dvb` 有专门提示分支

## 5. 第三方客户端实现清单（要复刻字幕功能需要做的事）

1. `GET /stream/list/:item_guid` → 拿 `subtitle_streams[]` + `video_streams/audio_streams`（guid 用于 play）
2. `POST /play/info {item_guid, media_guid}` → 官方推荐的默认 `video_guid/audio_guid/subtitle_guid`
3. `POST /play/play` → `play_link`（m3u8）；HLS 客户端会自动处理内嵌 WebVTT 字幕轨
4. 外挂字幕：`GET /subtitle/dl/:guid` 取内容；ASS 建议用 libass 系渲染器（JASSUB/libass-wasm）
5. 切轨：`media.resetSubtitle`（转码会话内）/ 本地切换（外挂）
6. 会话结束：`media.quit`（实测 `{"result":"succ"}`）

## 6. 接口字段手册（请求/响应逐字段）

### 6.0 通用请求头（所有 /v/api JSON 接口通用）

| Header | 值 | 说明 |
|---|---|---|
| `Authorization` | 媒体 token（32 位 hex，**无 Bearer 前缀**） | 登录后必带；`/auth`、`/sys/version`、`/server/info` 等除外 |
| `authx` | `nonce={N}&timestamp={T}&sign={S}` | 请求签名，算法见下 |
| `X-Trim-Client` | `web` | 客户端类型 |
| `X-Trim-Client-Version` | `616` | 前端版本 |
| `Content-Type` | `application/json` | 有 body 时 |

**authx 签名生成**（哈希一律 MD5）：
```
apiKey = "16CCEB3D-AB42-077D-36A1-F355324E4237"
salt   = "NDzZTVxnRKP8Z0jXg1VAMonaG8akvh"
GET:  bodyHash = MD5(urldecode(按key排序的query串))；无参数 = MD5("")
POST: bodyHash = MD5(JSON.stringify(body))   ← 与实际发送字节完全一致（紧凑序列化、无空格）
nonce = 100000~999999 随机数；timestamp = 毫秒时间戳
sign  = MD5(salt_path_nonce_timestamp_bodyHash_apiKey)   ← 下划线拼接
免签名：精确 /v/api/v1/task/running、/v/api/v1/play/record、/v/api/v1/subtitle/upload；
        前缀 /v/api/v1/{sys/img/, img/, concat/, media/}
```

### 6.1 `POST /v/api/v1/auth` — FN Connect code 换媒体 token

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `source` | string | ✅ | 固定 `"Trim-NAS"` |
| `code` | string | ✅ | `/oauthapi/authorize` 签发的一次性 code |

响应：`{"code":0,"msg":"","data":{"token":"37bb5975126f4cc091e1352b0b8ce9c7"}}`
错误：`11004` code 无效/过期；`-1` 缺 source/code。仅需 authx，无需 Authorization。

### 6.2 `POST /v/api/v2/user/loginByPassword` — 媒体密码登录（不走 FN Connect 的替代）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `username` | string | ✅ | 用户名 |
| `password` | string | ✅ | **SHA-256(明文密码) 的 hex**（前端用 js-sha256 预处理） |
| `remember` | bool | ❌ | 记住用户名 |

响应 `data.token` 即媒体 token；此接口走 v2 通道（前缀 `/v/api/v2`）。

### 6.3 `GET /v/api/v1/stream/list/{item_guid}` — 流信息（字幕轨来源）

路径参数：`item_guid` = 影片/剧集条目 guid。
响应 `data` 四个数组：

```
files[]            → {guid(文件guid), path, file_name, size, can_play, play_error, ...}
video_streams[]    → {guid(★play用), media_guid, codec_name:"hevc", profile:"Main 10",
                      width:3840, height:1604, resolution_type:"4k",
                      color_range_type:"DolbyVision", pix_fmt, index, ...}
audio_streams[]    → {guid(★play用), codec_name:"eac3", channels:6, language, index, ...}
subtitle_streams[] → {guid, media_guid, title, language:"chi", forced, index, is_default,
                      is_external(0内嵌/1外挂), codec_name("subrip"/"ass"/"webvtt"/"hdmv_pgs_subtitle"),
                      format("srt"/"ass"/"vtt"/"sup"), trim_id, Source("opensubtitles"等),
                      extra_file(0/1), is_bitmap(0/1), file_size, create_time, update_time}
```

### 6.4 `POST /v/api/v1/play/info` — 播放前取官方推荐 guid

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `item_guid` | string | ✅ | 影片条目 guid |

响应 `data`（实测）：
```json
{"guid":"d574303c...","type":"Movie","media_guid":"83ada7fd...",
 "video_guid":"67e2499a...","audio_guid":"4369e404...","subtitle_guid":"6f262517...",
 "play_config":null,"ts":0,"item":{"title":"电锯人剧场版 蕾塞篇","imdb_id":"tt30472557",...}}
```
`video_guid` = video_streams[0].guid（**不是文件 guid**，传错报 1001 System busy）。

### 6.5 `POST /v/api/v1/play/play` — 发起播放/转码会话

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `item_guid` | string | ✅ | 影片条目 guid |
| `media_guid` | string | ✅ | 媒体文件 guid（files[].guid / subtitle 条目里的 media_guid） |
| `video_guid` | string | ✅ | **视频流 guid**（video_streams[].guid） |
| `video_encoder` | string | ✅ | 目标编码，转码 `"h264"`；直通场景可空 |
| `resolution` | string | ✅ | `"宽x高"`，如 `"1920x1080"` |
| `bitrate` | int | ✅ | 目标码率 bps，如 4000000 |
| `startTimestamp` | int | ✅ | 起播秒数（续播位置） |
| `audio_encoder` | string | ✅ | 目标音频编码，如 `"aac"` |
| `audio_guid` | string | ✅ | 音频流 guid（audio_streams[].guid） |
| `channels` | int | ✅ | 声道数，如 2 |
| `subtitle_guid` | string | ❌ | 选中的字幕轨 guid；空=关字幕 |
| `forced_sdr` | int | ❌ | 1=强制 SDR（杜比视界/HLG 转码时） |
| `without_stream` | bool | ❌ | 仅取播放配置不实际串流（特定网盘场景） |

响应（实测，内嵌字幕场景）：
```json
{"play_link":"/v/media/29ef304c9786ca0aa1eaa5882fb55eb7/preset.m3u8",
 "is_subtitle_external":0,"subtitle_link":"","subtitle_index":8,
 "subtitle_guid":"6f262517...","audio_index":1,"video_index":0,
 "hls_time":4,"non_fatal_errno":null,"video_encoder":"","not_supported_resolution":"","supported_highest_resolution":""}
```
错误：`1001 System busy`（常见于 video_guid 传错）；`-6 Not Found`（guid 不存在）。

### 6.6 `GET {play_link}` — 转码 HLS 主播放列表

`play_link` 为相对路径，同源拼接；响应即 m3u8 文本（实测）：
```
#EXT-X-MEDIA:TYPE=SUBTITLES,GROUP-ID="subs",NAME="SUBS",DEFAULT=YES,FORCED=YES,AUTOSELECT=YES,URI="subtitle.m3u8"
#EXT-X-STREAM-INF:BANDWIDTH=4000000,...,SUBTITLES="subs"
main.m3u8
```
`subtitle.m3u8` = WebVTT 分段列表（内嵌字幕转换后就在这里）；`main.m3u8` = 视频分段。

### 6.7 `POST /v/api/v1/media/p` — 播放会话控制（RPC 信封，路径免签名）

公共字段：`req`（RPC 方法名）、`reqid`（固定 `"1234567890ABCDEF"` 即可）。

| req 值 | 专有字段 | 说明 |
|---|---|---|
| `media.resetSubtitle` | `playLink, startTimestamp(int秒), subtitleIndex(int)` | 转码会话内切字幕轨，视频流不动 |
| `media.resetQuality` | `playLink, quality{resolution,bitrate}, startTimestamp, clearCache:true` | 切画质（会重起视频流） |
| `media.resetAudio` | `playLink, audioEncoder, channels, audioIndex, startTimestamp` | 切音轨 |
| `media.quit` | `playLink` | 结束会话释放转码器，响应 `{"result":"succ"}` |
| `media.checkPlayLink` | `playLink` | 校验会话有效性（`errno:4100`=文件丢失） |
| `media.transcodeStatis` | `playLink`（查询）/ `result,resolution,bitrate,transcoded`（上报） | 转码统计，30s 一次 |

### 6.8 `GET /v/api/v1/subtitle/dl/{guid}` — 下载字幕内容（免签名）

| 参数 | 位置 | 必填 | 说明 |
|---|---|---|---|
| `guid` | path | ✅ | subtitle_streams[].guid |
| `fmt` | query | ❌ | 强制转码目标格式，如 `fmt=vtt`（前端在 Safari 等场景对 ass 强制转 vtt） |

响应：**字幕文件原文**（非 JSON），`Content-Type: application/octet-stream`，实测返回 `WEBVTT\n\n1\n00:01:18.320 --> ...`。仅需 Authorization + authx。

### 6.9 `POST /v/api/v1/subtitle/search` — 在线搜索字幕

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `lan` | string | ✅ | 语言代码，如 `"chi"`、`"zh-CN"` |
| `media_guid` | string | ✅ | 媒体文件 guid |

响应 `data.subtitles[]`：`{trim_id(关联站内条目), title, language, ...}`，`trim_id` 与 stream/list 字幕的 `trim_id` 对应。

### 6.10 其他字幕接口

| 接口 | 请求字段 | 说明 |
|---|---|---|
| `POST /subtitle/predownload` | `{media_guid, subtitle_guid}` | 预下载相似字幕 |
| `POST /subtitle/download` | `{media_guid, subtitle_guid, ...}`（与搜索结果条目对应） | 下载入库（自动转 vtt 存储） |
| `PUT /subtitle/mark` | `{media_guid, filepaths:[...]}` | 标记本机字幕文件关联 |
| `DELETE /subtitle/del` | `{subtitle_guid}` | 删除外挂字幕 |
| `POST /subtitle/upload/{media_guid}` | multipart 文件体（免签名） | 上传本机字幕 |

### 6.11 `POST /v/api/v1/play/record` — 播放进度上报（免签名）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `item_guid` | string | ✅ | 影片 guid |
| `media_guid` | string | ✅ | 文件 guid |
| `ts` | int | ✅ | 当前播放位置秒（直播固定 0） |
| `play_link` | string | ❌ | 转码会话链接（存在才带） |
| `resolution` / `bitrate` | string/int | ❌ | 当前画质（存在才带） |
| `audio_guid` / `direct_link_audio_index` | string/int | ❌ | 直连音轨（存在才带） |

节流：15 秒周期上报 + 起播 1 秒首报；暂停/结束补报；1 秒内同进度去重。

### 6.12 `POST /v/api/v1/item/list` — 条目列表

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `page` | int | ✅ | 页码，从 1 起 |
| `num` | int | ✅ | 每页数量（实测 85 可用） |

响应 `data`: `{total:85, list:[{guid, title, type("Movie"/"TV"/"Directory"/...), poster_list, media_stream:{resolutions,audio_type,color_range_type}, season_number, episode_number, ancestor_guid, ...}]}`。
过滤 Directory 类型后即影片/剧集条目。

### 6.13 `POST /v/api/v1/stream` — 直链/串流信息（direct-link 模式）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `media_guid` | string | ✅ | 媒体文件 guid |
| `ip` | string | ✅ | 客户端出口 IP（浏览器端用指纹库生成 visitorId） |
| `header` | object | ✅ | `{"User-Agent":["<UA 字符串>"]}`，防盗链指纹 |
| `level` | string | ❌ | `"Required"` / `"Optional"`（直链必需程度） |

响应含 `file_stream`、`video_stream`、`audio_streams`、`subtitle_streams`、`direct_link_qualities[{url, expired_at}]`（直链续期机制见周期文档 §5）。
