动效细节

让"犹豫"可被感知的四个设计决定

一条闭合曲线

轨道、飞离、外圈巡航、归来全部是同一路径的连续段，衔接点切线方向一致。飞走和回来不靠淡入淡出拼接，是物理上真的一只鸟。

Flutter: Path + PathMetric.getPosAtDistance / getTangentAtDistance

速度会呼吸

盘旋段匀速滑翔，接近顶点平滑减速到近乎悬停，停顿约 1 秒后沿切线加速冲出。全程无速度突变，节奏即情绪。

时间→弧长映射: 分段 smoothstep 关键帧积分

真·扑翼形变

燕形剪影经控制点形变生成「上拍 / 原位 / 下拍」三个同构关键帧，运行时数值插值还原扇翅；悬停时高频浅颤、滑翔时舒展慢拍，振翅与速度互为因果。

三帧同构 path 数值 lerp；freq/amp 由速度权重混合驱动

取色即换装

渐变三档色由动态取色种子经 HSL 明度偏移派生；悬停光晕与残影同源，取任何色都协调。品牌页可切回 Logo 原生渐变。

ColorScheme 种子 → HSLJitter(±0.06L) → 3 档 Gradient stops
