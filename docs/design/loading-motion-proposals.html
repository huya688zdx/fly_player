Fly Player · Loading Motion

流光加载动效提案

六套候选方案，全部基于 App 现有色板（深海军蓝底 + AppAccentTone 强调色），落地后随用户主题换色。每一套都可以单独用在全屏、区块或局部场景。

现状 — 默认 CircularProgressIndicator，28 处直接散落调用，无统一规范，观感廉价且与深色氛围脱节。

A · 弧光 Comet

全屏 / 区块通用

渐变彗尾 + 白热头部光点，扫过一圈带缓动的弧线。速度曲线带轻微加减速，比匀速旋转更有"呼吸感"，是最接近高端播放器的经典形。

CUSTOMPAINTER — SweepGradient 画弧 + MaskFilter 发光，旋转用 AnimationController ease 曲线

B · 光核 Halo

全屏留白场景

中心光点呼吸，涟漪三连向外扩散。极简、安静，适合首页这种大面积留白的等待，不抢氛围背景的戏。

CUSTOMPAINTER — 三个错相扩散圆环 + 中心点缩放，纯动画零图片资源

C · 律动条 Reverb

播放器 / 媒体语境

五根渐变光柱错相律动，向"声波/均衡器"隐喻靠拢，媒体属性最强。建议保留给播放相关加载（弹幕匹配、音轨切换）形成语义区分。

WIDGET — 5 个 AnimatedContainer 错相 scaleY，实现最简单

D · 双星 Orbit

连接 / 同步场景

两颗光点沿椭圆轨道对转，"环绕 NAS / 建立连接"的隐喻直观，适合连接页、媒体库扫描、同步等长任务。

CUSTOMPAINTER — 椭圆参数方程驱动两点相位运动，可加前后景深缩放

E · 海报骨架 Shimmer

列表 / 网格专用

不是转圈，而是内容本身的"占位剪影"：海报比例卡片 + 文本行，一道微光斜扫。等待结束内容原位浮现，无跳变——首页、搜索、收藏列表的最佳答案。

WIDGET — 按现有海报栅格做骨架组件 + ShaderMask 流光，可与分页加载复用

Loading

F · 顶栏光轨 Line

页面顶部 / 局部

3px 细光轨来回扫动，贴页面顶部或区块内嵌，不占据版面空间。适合已有内容、只等一小块数据的场景（分类切换、分页追加）。

WIDGET — 单个渐变条位移循环，可作为统一 LoadingLine 组件全局引用

建议组合

推荐落地方案

  • 全屏首屏加载A 弧光（或 B 光核），替换 connection_screen / startup_gate 等处的转圈
  • 海报列表 / 网格E 海报骨架，替换首页、搜索、收藏、分类的整页 Loading，并可下探到分页 footer
  • 局部 / 已有内容F 光轨，替换按钮旁、区块内的小型转圈；播放相关场景可引入 C 律动条做语义区分
