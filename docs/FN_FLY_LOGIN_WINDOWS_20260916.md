# 飞翔账号 FN 应用入口登录测试交付

## 范围

目标是允许飞翔账号使用 `https://<FN ID>.fnos.net/app/fly-data-service` 登录：先在现有 FN 入口页面完成远程访问授权，再校验飞翔服务实例，最后提交飞翔账号密码。保留完整应用前缀。

本轮不改后端、Docker、VPN、NAS 配置、媒体绑定架构或播放策略；基线为 `aa6087b7e26176b7448afba173071eb5f15f290e`，保留此前登录页和媒体来源精简。

## 实现与边界

- 复用 `EmbyFnEntryLoginPage` 和网页桥接，补齐 Windows WebView2 支持。飞翔只接受回到 HTTPS 同源 `/app/fly-data-service` 应用路径后的 `entry-token`，NAS 桌面上的早期令牌不会完成授权。
- 飞牛影视页面与入口页面都让 WebView 控制器自动复用默认环境，避免两种登录页先后打开时重复初始化。影视 OAuth 没有接入飞翔账号认证。
- 飞翔密码不传给 FN 网页。API 保持严格证书校验、不跟随重定向，先 `GET /system/identity`，再 `POST /auth/login`；登录历史中的实例身份约束保持有效。
- 精确应用地址和 FN 令牌随飞翔会话保存在安全凭据存储。后续账号、同步、图片、弹幕、BIF、播放活动请求从捕获的会话创建 API；Cookie 只发到该 origin 的应用 API 路径，不共享给媒体连接。
- 取消授权返回原表单并提示可重试。已登录账号页提供“重新授权 FN 访问”；重新授权仍核验实例及原用户，排队期间切账号或地址会拒绝旧令牌。

## 本地验证

- 第一轮相关测试：128 项通过，涵盖飞翔登录与历史、账号作用域、页面布局、飞牛 FN 和 Emby 入口令牌传输。
- 收尾后定向测试：64 项通过，涵盖 Windows 网页返回、应用前缀与恢复、凭据范围、API 响应限制、账号流转、弹幕缓存、BIF 和播放活动。
- 页面错误提示调整后复跑 29 项页面测试通过；Windows 网页生命周期与返回流程最终复跑 8 项通过。
- 新增测试仅两个：一个 Windows 授权返回主路径，一个 FN 凭据范围及授权页失败路径；复用现有 HTTP 测试验证带前缀登录恢复。
- 变更文件静态分析通过；Windows Debug 构建通过。具体输出见交付目录 `evidence` 中的 `analyze.log`、`windows-build-final.log`。第三方插件有既有 CMake 开发警告，未阻止构建。
- 依赖缓存使用 `F:\tmp\fly-merge-pub-cache-20260915`，临时文件与构建输出使用 `F:\tmp\fly-fn-login-20260916`。既有 F 盘 libmpv/ANGLE 包经构建脚本规定的 MD5 核对后复用；未修改依赖源码或锁文件。
- 本轮未使用 C 盘 Pub/Gradle 缓存；源码工作树及技能/记忆文件仍位于 C 盘。NuGet 包及缓存也定向到本轮 F 盘目录。

## 启动和联机测试

测试包位于 `F:\fly_player_packages\fly-fn-login-20260916-debug`。保持 `app` 文件夹完整，直接运行 `app\fly_player.exe`；不要单独拷贝 exe。Windows 需已安装 WebView2 运行时。本轮只构建，未启动客户端、未接管桌面、未提交真实凭据。该构建沿用软件正常用户数据位置，不是隔离账号沙盒。

网络恢复后：

1. 进入飞翔登录页，输入完整 FN 应用链接及飞翔账号密码，点击登录。
2. 在弹出的 FN 页面完成 FN 远程访问授权。此处输入的是 FN 访问所需身份；飞翔密码由播放器在实例检查后提交。
3. 确认授权页自动返回播放器，成功显示该飞翔账号的媒体来源；验证刷新列表、图片和需要的飞翔服务请求。
4. 重启测试包，确认保存的地址仍含应用前缀，当前会话可以恢复访问。
5. 验证取消授权可以重新登录；FN 授权失效时可用“重新授权 FN 访问”恢复。飞翔令牌自身失效则重新登录飞翔账号。
6. 分别回归服务根地址登录、飞牛 FN 登录和 Emby 登录；两类 FN 页面可按任意顺序打开。

## 尚未现场验证

当前 VPN 至 NAS 数据通道不可用，未探测真实 FN 链接，也未验证真实账号登录。后端源码与历史部署记录证明固定前缀约定，但不证明当前公网可达。仍需核实 FN 应用是否仅需要可读的 `entry-token`、是否另需 HttpOnly 状态、实际签发及失效流程、代理是否透传 Bearer，以及 Windows WebView2 的真实页面返回表现。若远端另有访问状态要求，当前实现会安全失败并提示重新授权；本交付不宣称已经真实登录成功。
