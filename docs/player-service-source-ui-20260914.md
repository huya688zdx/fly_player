# 播放器服务来源界面

用户要求：删去“飞翔已核验”等说明，让弹幕源适配当前飞翔登录，普通飞牛/Emby登录不展示服务专用功能。

## 实施范围

1. 以 B 线 OPED 成果及新版登录记忆/界面的合并基线 `3707331` 修改；原 B、自动连接及主目录保留。
2. 桌面与 Android 共用当前会话及绑定范围判断；保存了飞翔账号不等于本次播放使用飞翔账号。
3. 在原弹幕源页面加入“服务弹幕”和手动获取，读取当前文件已有服务缓存。未命中保留已选来源，不触发采集、模型调用或原站搜索。
4. 异步边界检查账户、绑定、媒体及请求代次。退出账号后仅清服务来源；切换至其他来源后迟到结果不能覆盖。
5. OPED 简化为“服务片头片尾”等功能文案，保留核验、文件身份和发布规则。

## 验证与交付

先验证登录模式、缓存命中/未命中及迟到回调，再构建 Windows 并检查实际窗口。Android 完整编译及独立 Kotlin 测试；没有设备时实机播放标为 NOT_RUN。测试数据用于边界验证，不作为真实服务弹幕命中证明。

没有数据库迁移或 NAS 部署。Windows 构建、依赖、缓存、临时文件与隔离运行数据全部位于 E 盘。测试配置源于已有本机配置，媒体服务的续播和观看记录按正常播放链上报。回滚可以使用保留的旧程序；源码回到隔离树的 `3707331`，无需还原账号或历史数据库。
