# 已绑定来源的自动连接与界面融合

本轮按用户要求直接修复现有流程，保留原播放器、原账号绑定和播放链。

## 已确认原因

`activateFlyBinding` 只要看到多个客户端地址就弹窗；`FlyAccountController.activate` 已写入 `fly.address.<accountKey>.<bindingId>`，却没有读取。后台已通过 bindings / device-access 下发完整授权地址和媒体实例 ID，因此本问题无需新增服务 API 或反复重新登录。

## 实施边界

1. 普通进入/切换来源直接调用 activate。仅用户主动打开连接设置时使用原项目已有选择组件。
2. 每次以新 device-access 的地址为准；优先探测当前账号、当前绑定上次成功且仍授权的地址，再尝试其他入口。显式手选失败不偷偷替换。
3. 每个自动探测最多 3 秒，总预算 12 秒。只发公共身份请求，严格 TLS、无 token/cookie、禁止重定向；确认实例 ID 一致后应用媒体凭据。没有可靠地址则保留当前连接和偏好并显示简洁提示。
4. 独立 UI 分支复用已有 TrackOptionSheet、AppActionSheet、确认弹窗、说明气泡和页面表单样式。保持原路由、授权、目录操作和手机/桌面适配。
5. 已绑定的媒体地址自动下发，无须每台设备重复输入。首次仍需提供飞翔入口；同 NAS 不等于同端口或同外网路径，不根据飞翔地址盲目改端口或发送媒体凭据。

## 验证

- controller 使用真实 loopback HTTP fixture 测试失败入口、切源后记忆、网络改变后回退、失败不覆盖连接、不同账号偏好隔离。
- selector 测试新授权集合、排序/去重、过期偏好、手选与总时间预算；原 TLS/身份测试继续运行。
- widget 验证日常切源不弹连接框，手动入口使用原组件，表单/说明与原项目一致。
- 所有新依赖和测试产物位于 E，使用锁定的 pub.dev 依赖；缺少 Android/Windows GUI 条件时明确未实机验证。

原始与 A/B 功能分支均保留。这里使用从脱敏 `dbd2112` 创建的独立 worktree；服务端/生产 NAS 不在本次修改范围。

## 本轮实际交付

- 账号与媒体来源、首页来源菜单、同步节目与历史说明已接回原有选项面板、确认弹窗、表单、说明浮层和轻提示。Android 保留原底部/横屏组件；PC 使用后文补充的专用桌面浮窗。已授权来源普通切换不再弹出选址框。
- 主动打开「连接设置」时才列出具体地址，并只为同账号、同绑定、同版本的当前连接标记选中项。旧弹窗在账号或绑定版本变化后不能继续提交。
- 根据用户提供的安卓「选择字幕」截图检查原有组件。保留其标题/行文字、22 dp 圆形标记、独立选中卡片和渐变公式，没有硬编码绿色或另改原生字幕面板。
- 修复共用弹层跨路由丢失页面局部 Theme、Runtime 和 Snapshot 的问题；上层全局颜色继续实时更新，局部 false/null 遮蔽规则保留。说明浮层也保留调用页面的主题。
- 去掉半透明账号/历史卡片的投影，避免浅色主题出现整块灰底。轻提示使用调用页面文字色，并在超时后主动请求下一帧，保证安静页面也能自动消失。

## 已执行的验证与边界

2026-09-13，合并后选择 31 个受影响测试文件，**187 项通过，无跳过**；24 个修改或新增 Dart 文件静态分析通过。包括真实 loopback HTTP 失败入口/身份验证、TLS/重定向拒绝、挂起请求实际关闭、账号隔离、真实隔离 Python API 合同测试，以及原有弹层/目录/观看统计组件回归。合并测试运行约 18 秒；这不是 NAS 性能数据。

探测限制是每个媒体地址最多 3 秒、每轮总预算 12 秒（不含获取 device-access 的服务请求）。无可验证地址时不应用新凭据或覆盖成功偏好；服务端只有 nas_api 时明确提示管理员登记客户端地址。

预览包含 390 dp 正常布局、浅深主题、模拟键盘/大字布局，以及与参考图同宽、同内容、同选中状态的字幕面板。使用真实微软雅黑字体生成 widget 图，不是 Android 系统字体或实机截图。1.6 倍字体仅为压力测试。图片和日志留在 E 盘 build/.task-tmp，不把测试截图当作手机或 Windows 实播验收。

本轮未修改数据库结构、原生播放链或遮罩算法；未部署生产 NAS。实际外网/VPN 链路及安卓 APK 安装后的显示、播放仍需实机验收；本轮自动回退发生于来源激活，不实现播放中更换线路。

Windows Release 已用现有 E 盘便携 SDK 实际构建通过，用时约 79 秒。独立产物位于本 worktree 的 `build/windows/x64-mask-p0-integrated/bundle/`；`fly_player.exe` 为 235,520 字节，`data/app.so` 为 15,745,968 字节。这仅证明可构建，尚未进行 GUI/播放实机验收。运行时需要保留 bundle 内 DLL 和 data，不能只复制 exe。

## 回滚

本次使用独立 `fix/automatic-bound-media-connection` 分支和 E 盘 worktree，保留脱敏基线 `dbd2112`。原工作区和旧可执行程序无需删除或替换。代码回滚可在独立工作区检出该基线，或逐笔 revert 本分支新增提交；不需要数据库降级，也不要用旧的未脱敏分支覆盖远端历史。
