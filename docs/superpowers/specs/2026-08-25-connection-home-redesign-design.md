# 飞翔播放器统一连接首页设计规格

日期：2026-08-25

## 1. 背景与目标

当前连接首页在飞牛影视、Emby、Jellyfin 之间存在明显的结构差异：飞牛额外显示访问协议和访问码，切换服务时表单高度与按钮位置发生变化；页面还存在品牌区比例失衡、颜色饱和度偏高、平板横向拉伸、服务器地址默认值包含个人域名、登录历史使用文字头像等问题。

本次改版采用已确认的“B · 一体登录卡”方向，将三个媒体服务放入同一套固定布局，并使用“深海雾蓝”配色。目标如下：

- 三种服务共享相同的布局骨架，切换时不改变表单和主按钮的位置。
- 移除独立的“访问协议”控件，统一服务器地址输入规则。
- 首次进入不预填任何真实服务器地址或个人域名。
- 手机与平板均有明确的自适应布局。
- 登录历史使用服务的真实 Logo，不再使用 `FN`、`E`、`JF` 文字头像。
- 将所有用户可见的产品名称统一为“飞翔播放器”。
- 保持现有认证、状态管理、登录历史、下载入口和 FN Connect 行为不变。

## 2. 范围与非目标

### 2.1 范围

- 连接首页 `lib/screens/connection_screen.dart` 的布局、样式与交互动画。
- 服务器地址的界面输入与规范化规则。
- 登录历史列表的视觉呈现与服务 Logo。
- Android 桌面名称及 Flutter 内所有用户可见的产品名称。
- 与上述行为直接相关的测试。
- 开始实现前，仅撤销 Luna 本轮对 `connection_screen.dart` 的修改，保留工作区其他现有改动。

### 2.2 非目标

- 不修改包名、Android applicationId、Dart 类型名或原生通道名。
- 不重写 `NasProvider`、Emby/Jellyfin API 或认证流程。
- 不改变登录历史的数据结构、持久化格式或已有用户数据。
- 不引入新依赖、字体或图片资源。
- 不重构与连接页无关的代码。

## 3. 视觉方向

### 3.1 风格

采用“深海雾蓝”色调：

- 页面背景为低明度深海蓝黑，不使用高饱和蓝色或绿色大面积填充。
- 登录卡、输入框和分段切换器通过明度差建立层次，避免多层高亮描边。
- 主按钮使用低饱和雾蓝，不使用青绿到亮蓝的渐变。
- 飞牛影视、Emby、Jellyfin 的 Logo 是页面中的主要彩色元素。
- 选中态使用轻微的雾蓝表面和细边界，不使用霓虹发光。
- 所有颜色从现有主题或主题扩展派生，同时保证浅色主题下的文本对比度。

### 3.2 品牌区

- 产品名显示为“飞翔播放器”。
- Logo、产品名与“连接你的媒体世界”组成紧凑品牌区。
- 手机端品牌区位于登录卡上方，不再占据大块首屏高度。
- 平板横屏时品牌区进入左侧说明栏；登录卡位于右侧。

## 4. 响应式布局

### 4.1 手机与窄窗口

- 使用单栏布局。
- 登录卡占据可用宽度，但保留安全边距。
- 页面由 `SafeArea` 和可滚动容器承载，键盘弹出后仍可访问全部字段和按钮。
- 服务名必须完整显示为“飞牛影视”“Emby”“Jellyfin”，不得使用省略号。

### 4.2 竖屏平板与中等窗口

- 当宽度为 600–839 逻辑像素时，继续使用单栏布局。
- 登录卡设置合理最大宽度并居中，不将输入框横向拉伸至整个屏幕。

### 4.3 横屏平板与大窗口

- 当宽度不小于 840 逻辑像素时使用双栏布局。
- 左栏展示 Logo、产品名、说明文案；右栏放置固定宽度登录卡。
- 屏幕旋转、窗口变化及大字体下不得出现横向溢出或控件重叠。

## 5. 统一登录卡

### 5.1 固定骨架

三个服务始终共享以下顺序：

1. 服务分段切换器。
2. 当前服务标题和辅助说明。
3. 服务器地址。
4. 账号。
5. 密码。
6. 保持登录与选项行。
7. 固定错误提示区域。
8. 登录主按钮。
9. 条件性次操作。

切换服务时，登录卡外框、三个主字段、错误区域和登录按钮的位置不得改变。

### 5.2 服务切换动画

- 选中背景在约 180ms 内平移，使用平滑减速曲线。
- 标题、辅助说明和字段内容使用约 120ms 的交叉淡化。
- 不对登录卡高度、字段位置或主按钮位置执行尺寸动画。
- 连续快速切换不得产生积压动画、闪烁或中间空白状态。
- 每个服务保留独立的输入状态；切换后返回时恢复该服务尚未提交的内容。

### 5.3 飞牛访问码

- 飞牛的访问码放入默认收起的“更多选项”。
- Emby 和 Jellyfin 不显示访问码输入框。
- 三个服务都保留相同高度的选项行；飞牛显示可点击的“更多选项”，其他服务不显示无意义文案。
- 从展开状态切换离开飞牛时自动收起；这是用户触发的局部展开，不改变服务切换的固定骨架要求。

### 5.4 次操作

- “登录”是唯一强主操作。
- “查看已下载数据”和“重新登录 FN Connect”使用低强调文本操作。
- “重新登录 FN Connect”仅在飞牛服务和现有业务条件满足时显示。
- 次操作不得挤压或移动登录主按钮。

## 6. 服务器地址规则

- 首次进入任何服务时，服务器地址值为空。
- 空字段只显示中性格式提示，例如 `https://nas.example.com`；提示不得进入控制器值或提交数据。
- 完整地址包含 `http://` 或 `https://` 时原样使用。
- 裸域名或 IP 在提交前自动补 `https://`。
- 显式填写 `http://` 时不得自动升级为 HTTPS。
- 只有以下两种情况可以回填真实地址：已有“保持登录”数据，或用户主动选择登录历史。
- 删除任何个人域名硬编码、示例值或隐式默认值。
- 地址规范化必须在统一、可测试的逻辑中完成，不得在不同服务的 UI 分支中重复实现。

## 7. 登录历史

- 列表行使用 `MediaBackendRegistry` 或对应后端描述符提供的现有真实 Logo。
- 飞牛影视使用 `lib/img/feiniu_Logo.png`，Emby 使用 `lib/img/Emby_logo.png`，Jellyfin 使用 `lib/img/jellyfin_logo.png`。
- 不显示 `FN`、`E`、`JF` 文字头像。
- 每行展示服务器地址、账号和服务名称；长地址单行省略。
- 点击整行后切换到对应服务并回填该条历史记录。
- 删除单条和清空全部历史的现有行为保持不变。
- 列表在手机和平板上使用限宽内容区域，平板不把每行无限拉宽。

## 8. 产品改名

- Android 桌面名称、连接页、设置/关于页及其他用户可见文案统一使用“飞翔播放器”。
- 本地化资源中的旧产品名同步更新，避免不同语言或不同页面出现名称不一致。
- 包名、applicationId、类名、文件名、数据库名和通道名保持不变。

## 9. 状态、数据流与错误处理

- 飞牛登录继续通过 `NasProvider` 和现有统一错误处理提交。
- Emby/Jellyfin 继续通过对应 API 验证，并保存现有 `MediaBackendConnection`。
- 服务选择继续由后端注册表驱动，不写死只支持当前三个后端的不可扩展分支。
- 登录历史继续由 `LoginHistoryStore` 读取和写入。
- 地址历史回填、密码/访问码显隐、键盘 Done 提交和保持登录语义保持不变。
- 校验错误和网络错误显示在固定错误区域；错误出现和消失不得推动主按钮或整张登录卡跳动。
- 提交期间保持现有防重复提交和加载状态，切换服务不得让旧请求的结果覆盖当前服务界面。

## 10. 无障碍与输入适配

- 控件保持语义标签、合理触控尺寸和清晰焦点顺序。
- 支持系统大字体；服务名称、地址和错误文案不得相互覆盖。
- 密码与访问码显隐按钮保持可访问标签。
- 键盘弹出后页面可滚动到当前字段和登录按钮。
- 动效遵循系统减少动态效果设置；启用时缩短或取消非必要过渡。

  - 各服务输入状态独立保留。

### 11.3 视觉验收

- 手机首屏可看到完整品牌区、服务切换器、三个主字段和登录按钮。
- 三服务快速往返切换时，卡片和按钮无上下抖动。
- 平板竖屏为限宽单栏，横屏为双栏，均无过度拉伸。
- 深海雾蓝配色低饱和、层级清晰，服务 Logo 是主要彩色元素。

1. 精确识别并撤销 Luna 本轮对 `connection_screen.dart` 的修改，不影响该文件中此前属于用户的变更，也不触碰其他脏文件。
2. 先补充或更新能够证明统一骨架、地址规则和平板适配的测试。
3. 实现连接首页和登录历史视觉变更。
4. 完成全局用户可见产品名替换。
5. 运行格式化、静态分析、相关测试、全量测试及可用的 Android 构建验证。
