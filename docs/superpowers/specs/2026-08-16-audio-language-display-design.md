# 详情页音轨语言中文显示设计

## 目标

详情页“选择音频”面板应把标准语言码转换为中文名称，例如 `jpn` 显示为“日语”、`eng` 显示为“英语”，同时保持播放器和后端继续使用原始语言码。语言表应覆盖常见媒体文件使用的 ISO 639-1、ISO 639-2/B 与 ISO 639-2/T 别名，而不是只处理截图中的 `jpn`。

## 现状与原因

`MediaLanguageMapper` 已经维护 `jpn/ja/jp -> 日语` 等映射，但详情页音轨面板直接使用 `AudioTrackOption.displayLabel`。该属性为保持模型层与界面语言无关，只返回标准化语言码，因此面板显示了 `jpn`。

## 方案

在详情页展示层增加一个音轨标题转换入口：

- 已知语言码通过 `MediaLanguageMapper.languageName` 显示中文名称。
- 保留现有中、英、日、韩及欧洲常见语言映射，并补齐常见亚洲、中东和其他媒体语言，包括波斯、乌尔都、孟加拉、泰米尔、泰卢固、马拉雅拉姆、卡纳达、旁遮普、尼泊尔、缅甸、高棉、老挝、蒙古、哈萨克、菲律宾、格鲁吉亚、亚美尼亚、阿塞拜疆、冰岛、爱尔兰、威尔士、巴斯克、阿尔巴尼亚、波斯尼亚和马其顿语等。
- 每种语言同时接受常见的两字母代码、三字母术语代码、三字母书目代码及英文名称别名；只有一个标准三字母代码的语言不重复造别名。
- 没有中文映射的非空语言值回退为原始值，避免出现空白标题；`und`、`unknown`、`zz-unknow` 等明确的未知标记仍显示为空。
- 详情页当前音轨摘要与“选择音频”面板共用该入口，避免同一轨道在两个位置显示不一致。
- 不改 `AudioTrackOption.displayLabel`，避免破坏模型层的国际化中立约束。

## 数据流

原始音轨语言码进入 `AudioTrackOption` 后保持不变。详情页生成当前音轨摘要或面板条目时，调用展示层转换入口得到中文标题；用户选择轨道时仍按原有 `guid` 和原始语言码完成切换。

## 测试

通过 `PlayDetailTrackSelector` 的单元测试覆盖：

- `jpn` 显示“日语”。
- `eng` 显示“英语”。
- 从欧洲、南亚、东南亚及中东语言中选取代表性两字母、三字母和书目代码，验证都能得到中文名称。
- 未收录的非空代码原样显示，明确的未知标记保持空标题。
- 已有详情页音轨选择逻辑不受影响。
