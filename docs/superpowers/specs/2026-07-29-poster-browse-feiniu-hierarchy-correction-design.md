# 海报浏览飞牛层级纠错设计

## 目标

修复飞牛后端在海报浏览页把媒体库目录“动漫 TV”误当成剧集的问题。修复后：

- “动漫 TV”仅作为后端返回的第二行目录名称，显示在“继续观看”旁边；名称不写死。
- 继续观看卡片与左上角信息区显示真实剧集名，不显示媒体库目录名。
- 继续观看卡片使用真实剧集竖版封面，大屏背景使用真实剧集横版背景，标题区域使用真实剧集 Logo。
- 点击播放仍播放原始单集，不把剧集或目录 ID 当作播放目标。

本次只纠正飞牛数据层级和第二行目录识别，不再改动已经确认的布局、手机横屏背景、图片尺寸和轮播间距。

## 已确认的层级语义

飞牛单集条目中的字段按以下语义处理：

- `guid`：当前单集 ID，也是播放目标。
- `parent_guid`：季 ID。
- `ancestor_guid`：顶层媒体库目录 ID，例如“动漫 TV”；绝不能作为剧集 ID。
- `ancestor_name`：顶层媒体库目录名称；绝不能作为剧集名称。
- `tv_title`：可能是剧集名，也可能被飞牛污染成与 `ancestor_name` 相同的目录名。
- 播放信息的 `grand_guid`：优先作为剧集 ID 候选，但必须排除当前单集 ID、季 ID 和顶层目录 ID。

如果 `tv_title` 去除首尾空白后与 `ancestor_name` 相同，则把它视为无效目录标题，不参与显示回退。

## 剧集 ID 解析

解析过程只在选中条目需要补全素材时执行：

1. 读取当前单集的播放信息，取得 `grand_guid`。
2. 若该值非空，且不同于单集 ID、季 ID、`ancestor_guid`，则将其作为真实剧集 ID。
3. 若候选无效或缺失，则按 `parent_guid` 获取季详情，再读取季详情的 `parent_guid` 作为剧集 ID。
4. 季详情得到的 ID 同样必须排除单集、季和顶层目录 ID。
5. 无法解析时，不使用 `ancestor_guid` 兜底；保留单集自身标题和现有图片，避免再次显示目录信息。

解析成功后，以剧集 ID 请求剧集详情，并将该详情只用于展示素材补全。播放和详情入口仍保留原始单集卡片 ID。

## 标题与素材规则

对继续观看中的单集，展示顺序如下：

- 标题：真实剧集详情标题；其次是未被目录污染的 `tv_title`；最后是单集自身标题。
- 卡片海报：真实剧集竖版封面优先，再回退到季封面和单集现有候选图。
- 大屏背景：真实剧集横版背景优先，再回退到条目详情横版图、卡片背景和竖版封面。
- 标题 Logo：真实剧集 Logo 优先；加载失败时在固定标题槽位显示上述文字标题。

目录名称不进入标题、海报、背景或 Logo 的候选链。

## 第二行目录

飞牛后端不调用“最近添加”接口。加载媒体库目录后，按后端原始顺序选择第一个类型归一化后为 `tv` 或 `series` 的目录：

- 行标题直接使用后端目录的 `title`，例如用户当前配置的“动漫 TV”。
- 行内容使用该目录 ID 调用目录预览接口。
- 没有匹配目录、目录为空或请求失败时，仅隐藏第二行，不影响继续观看。

其他后端继续沿用现有“最近添加”逻辑。

## 性能与容错

- 有效 `grand_guid` 直接命中时不增加季详情请求。
- 只有候选无效时才请求一次季详情完成父链解析。
- 沿用现有会话级条目/剧集补全缓存和并发请求合并；快速切换卡片不重复请求相同详情。
- 解析或详情请求失败时采用本地回退，不阻塞播放，不批量预取全部剧集详情。
- 不新增图片滤镜、常驻图层或额外动画。

## 测试设计

采用测试驱动方式增加以下回归场景：

1. `tv_title == ancestor_name` 时，卡片不再显示目录名，且 `ancestor_guid` 不映射成剧集 ID。
2. 播放信息返回有效 `grand_guid` 时，使用该 ID 获取真实剧集详情。
3. `grand_guid` 等于顶层目录 ID 或缺失时，通过“单集 → 季 → 剧集”父链得到剧集 ID。
4. 剧集详情补全后，标题、竖版封面、横版背景和 Logo 均优先使用剧集素材。
5. 素材补全前后，播放卡片 ID 始终保持为原始单集 ID。
6. 类型为 `TV` 或 `Series` 的首个飞牛目录均可成为第二行，行标题和目录 ID 跟随后端。
7. 飞牛路径不调用“最近添加”；其他后端行为保持不变。

## 验收标准

- 用户截图中的左上角和卡片标题不再出现“动漫 TV”，而是各自真实剧集名。
- 继续观看中的《宫庙下的魔女》等条目显示对应剧集封面；选中后背景与 Logo 来自同一真实剧集。
- “动漫 TV”只出现在“继续观看”旁的第二个行选择器，且随当前后端目录名称变化。
- 播放行为、已确认布局、手机横屏显示和轮播间距无回归。
- 新增针对性测试通过，相关测试集与 `flutter analyze` 通过。
