# 启动直达海报首页设计

## 目标

在设置首页新增“启动直达海报首页”开关。开启后，应用每次启动并确认存在有效登录会话时，默认打开沉浸式海报浏览界面；关闭时保持当前普通首页行为。

## 用户行为

- 开关默认关闭，升级和首次安装均不改变现有启动体验。
- 设置说明为：“已有有效登录会话时，打开应用直接进入沉浸式海报浏览。”
- 开启后，冷启动或登录完成并进入主应用根入口时，自动打开 `/screen/poster-browse`。
- 海报页下方保留普通首页作为返回目标，用户按返回键后进入普通首页，不退出应用。
- 一次主入口生命周期只自动打开一次；从海报页返回后不会立即再次跳转。
- 外部详情路由、播放器、并行窗口副栏及用户手动打开海报页不受该设置影响。
- 重置应用设置时恢复为关闭。

## 架构

新增单一职责的启动偏好 Provider，使用 `SharedPreferences` 持久化布尔值并暴露加载完成状态。Provider 在应用顶层注册，设置页和主入口共享同一份运行时状态。

主入口增加启动目的地门控组件：先等待启动偏好、飞牛会话和服务器族会话加载完成；若没有有效登录，继续展示登录页；若已登录且开关开启，在首帧后只执行一次命名路由跳转。门控期间显示轻量加载状态，不先构建普通首页的数据列表，从而避免首页闪现和重复网络加载。

不修改全局初始路由解析。这样外部启动路由仍保持原语义，海报页也继续使用现有路由、方向恢复和返回逻辑。

## 设置界面

在设置首页基础设置组中加入自适应开关条目：

- 标题：启动直达海报首页
- 说明：已有有效登录会话时，打开应用直接进入沉浸式海报浏览。
- 默认值：关闭

设置搜索加入对应关键词，搜索结果定位到设置首页。保存失败时回滚开关并保持旧值。

## 性能与错误处理

- 偏好只有一个布尔值，不引入额外文件或后端请求。
- 设置与会话未就绪时不创建海报页或普通首页，避免两套页面同时加载。
- 跳转通过一次性状态保护，防止 Provider 重建、主题切换或屏幕旋转重复压入路由。
- 偏好读取失败时安全回退为关闭；保存失败时恢复旧值。

## 验证

- Provider 默认值、加载、保存和失败回滚测试。
- 启动门控测试：关闭进入普通首页；开启且已登录自动压入海报页；未登录不跳转；返回后不重复跳转。
- 设置页测试：显示正确标题、说明和开关状态，点击后持久化。
- 设置重置测试：该偏好包含在可重置键中。
- 运行相关 Flutter 测试、`flutter analyze`，构建并安装 profile 包进行冷启动日志检查。
