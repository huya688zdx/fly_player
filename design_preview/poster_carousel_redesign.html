容器永远 2:3、同圆角、同描边；图片按 cover 居中裁切铺满 —— 宽图裁上下、窄图裁左右，主体居中的海报基本不受影响。 Flutter 对应写法就是 AspectRatio(2/3) + BoxFit.cover，一个属性解决露黑。

03

方案 A 设计规格（可直接翻译为 dp）

卡片宽度46% 屏宽（≈180dp）
卡片比例2 : 3（高 ≈270dp）
圆角14dp
默认描边1.5dp · white 10%
选中描边2dp · #F2C94C + 15% 光晕
非选中态scale 0.86 + 黑色 45% 压暗
主标题13sp · white · maxLines 2
副标题11sp · white 52%（集数/进度）
进度条高 3dp · #F2C94C（仅继续观看）
间距卡片间 12dp · 与 Tab 间距 14dp
滚动viewportFraction ≈ 0.52 · 吸附居中
交互点侧边卡片 → 平滑换焦点
// 落地映射（Flutter 侧，示意） PageView.builder( viewportFraction: .52, // 卡片间 12dp + 吸附居中 itemBuilder: (_, i) => AnimatedScale( // 焦点态：scale 1.0 / 0.86 scale: isCenter ? 1.0 : .86, child: Column(children: [ AspectRatio(aspectRatio: 2/3, child: // 根治露黑 DecoratedBox(decoration: focusBorder, // 金色描边 / white10 描边 child: Image(image: p, fit: BoxFit.cover))), SizedBox(height: 44, child: Text(t, maxLines: 2)), ]))); // 继续观看：卡片底部叠 LinearProgressIndicator(3dp, #F2C94C)
